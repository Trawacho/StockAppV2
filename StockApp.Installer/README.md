# StockApp Installer

Der Installer wird mit [NSIS](https://nsis.sourceforge.io/) erstellt (über
Docker, keine lokale NSIS-Installation nötig). Die vollständige Anleitung zum
Bauen der `StockAppInstaller.exe` ist Teil des Gesamt-Release-Ablaufs und
steht in [`RELEASE.md`](../RELEASE.md) im Repository-Root (Abschnitt
"Installer (`StockAppInstaller.exe`) bauen").

## Voraussetzungen

- [Docker](https://www.docker.com/) installiert und gestartet
- .NET 8 SDK
